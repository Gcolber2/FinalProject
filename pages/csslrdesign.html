CSS Layout and Responsive Design

How CSS Can Effect Webpage Layouts

One very important feature of CSS is how it can be used to change the layout of the page itself using the box model, flexbox, and grid.


Box Model

The first main method is the box model which as it's name implies wraps a box of sorts around html elements. This box uses several different parts to function wich are as follows. The content which is the content of the box and represents the texts and images inside the box, Padding which affects how much space or area around the content is cleared for it, Border represents the border that wraps around the padding and content and where the box's totalwidth and height stops, and tbe Margin represents the area around the border while also representing how much total space the box takes up on the page. Following this are the Width and Height of an element which can be used to affect the content area. This includes the padding and borders as well so those must be taken into account when editing this function.


Flexbox and Grid

Flexbox and Grid are both layout modules using CSS for the purpose of editing webpage/website layouts. Flexbox is used for simpler one dimensional layouts with either rows or collumns and has a higher focus on flexibility. While Grid uses a two dimensional layout with both rows and collumns and is meant for easily creating complex web layouts. Both are useful in keeping things orderly for certain elements on a page or for the site in it's entirety and which one is used for which depends on the complexity of the site in question. Both are also good for designing a responsive layout structure which leads into the next segment.


Using CSS To Give a Site a More Responsive Design

Responsive web design is about using HTML and CSS to make your site respond to various different devices and view sizes by making itself viewable regardless of such. Like making content always stay in the scope of the screen regardless of how much one zooms in. Or changing it to better fit a specific device's screen space or viewing limitations.
