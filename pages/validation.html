How to Validate Your Code

Sometimes despite how many times you go over your code you can still miss an error that can cause problems later down the line. Thankfully there are tools to help catch these errors. These being the W3C HTML and CSS Validators. These serve the purpose of checking over your HTML/CSS Code and scanning for possible error that may have been missed. To use them is simple, you go to the webpage, select an option relating to whether you wish to validate a web address, the file itself, or if you wish to directly input specific markups to be validated.
