Accessibility

What Accessibility Is and How It Can Be Applied

Accessibility in websites is a thing of absolute importance for giving those with disabilities and impairments the ability to benefit from the internet as much as anyone else. For this page it will focus on how it's usually done via HTML and CSS accessibility practices. HTML's accessibility practices are most commonly seen in semantic html, color-contrast alt text in images, and color contrast. The former is seen for example in the form of replacing div elements with more descriptive ones depending on their purpose like button, article, table, header, footer, etc.
While Labels are used to describe certain html elements in even better detail for tools such as screen readers. One example is using a lable to describe what purpose a particular button serves when it is clicked on. Or it can be used to describe an input field such as if you wished to have someone input their driver's license you would label the place for that input as such. There are also higher levels of labeling used for forms requiring use of the fieldset element to encompase the form then the legened element to describe what the subject of the information being submitted into the form as a whole is leading into the labels for everything below those two that requires them.


Alt image Text

Also of great importance for those with visual impairments and also those running an operating system or browser that struggles or lacks support for certain image files or website features. We have Alternative Image Text using the alt attribute when posting an image. This makes it so that when an image doesn't load or if a screen reader goes accross the image a line of text will appear in it's place to explain what the image is/is supposed to be for the viewer and the screen reader to parse. This is also useful if an error occurs with the image itself on the host site so it extends beyond uses in pure accessibility while still connecting back to it in a way.

Color Contrast

Lastly there's color contrast on a webpage. This represents light and dark colors and how they interact with eachother and is important to understand for overall visibility even without factoring in accesibility concerns. For example lightly colored text on a lightly colored background can make it hard to see same with dark text on a dark background. While having overly bright text on a dark background while easier to see can at times cause irritation to the eyes if used in excess.
